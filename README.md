# Bullsonchain

Bullsonchain builds on crypto experience since 2017 and is now launched as a new project.  
This repository contains the source code and documentation for the Bullsonchain website.

---

## 📘 Project Purpose
The purpose of this project is to create a responsive, accessible, and user‑friendly website that introduces Bullsonchain and its community.  
The site highlights crypto experience since 2017 and provides a clear entry point for visitors.

---

## 🚀 Features
- Semantic HTML structure for clarity and SEO
- Responsive design with CSS for mobile and desktop
- Accessibility improvements (contrast, alt‑texts, redundancy fixes)
- Video introduction embedded with descriptive text
- Modular code structure for easy maintenance

---

## 🛠️ Technologies Used
- **HTML5** (semantic markup)
- **CSS3** (responsive layout, accessibility optimization)
- **JavaScript** (basic interactivity)
- **Netlify** (deployment and hosting)
- **Unstoppable Domains** (domain management)
